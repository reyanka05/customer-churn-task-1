# Task-1 Submission Checklist

Before submitting:

- [ ] Open `data_quality_analysis.ipynb` and confirm it opens correctly.
- [ ] Open `README.md` and confirm the project description is visible.
- [ ] Confirm `data/` contains the supplied dataset and cleaned dataset.
- [ ] Confirm `outputs/` contains the profile, quality report, outlier report, summary statistics, distributions and validation checks.
- [ ] Confirm charts are visible in `outputs/charts/`.
- [ ] Upload the contents of this folder to a **public GitHub repository** (or another permitted public/view-only location).
- [ ] Open the repository in an incognito/private browser window to confirm it can be viewed without requesting access.
- [ ] Copy the public repository URL.
- [ ] In the task's **Project URL** field, select **Data Quality and Exploratory Analysis / Task 1**.
- [ ] Paste the public repository URL.
- [ ] Click **Submit for review**.

Do NOT submit a private repository.
Do NOT submit the ZIP file itself as the Project URL.
